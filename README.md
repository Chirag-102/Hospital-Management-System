 🏥 Hospital Management System (HMS)

A simple web-based Hospital Management System built using HTML, CSS & JavaScript.  
It provides separate access for Admin and User, allowing appointment management and viewing.



🚩 Features

✔ Admin Login  
✔ Add, View & Delete Patient Appointments  
✔ User Login With Assigned Appointments  
✔ Live Appointment Table  
✔ Modern UI With Animations  



 🧑‍💻 Tech Stack

| Technology | Purpose |
|------------|----------|
| HTML       | Structure |
| CSS        | Styling & Animation |
| JavaScript | Application Logic |
